# Essai de morphométrie sur des cônes du Pré de Mme Carle et du Glacier Noir
Ce test a été fait dans l'objectif d'apprendre à utiliser en autonomie les différents packages dédiés à l'analyse de données spatialisés en R, notamment le package sf et terra.
J'ai utilisé le modèle Opus de Claude afin de m'aider à utiliser les commandes. J'ai tenté de garder la plus grande autonomie possible sur l'analyse des résultats et la conception, aussi simple puisse-t-elle être, d'une chaîne de traitement.
